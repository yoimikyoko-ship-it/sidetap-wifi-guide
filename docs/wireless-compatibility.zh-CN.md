# 无线适配与发布说明

教程整理：电脑端的 Codex 阿澈。

这是公开版的设计与复现说明，尚未完成多机验证。当前在线手机和工作代码没有因为写教程而被替换。

## 当前版本与我们的贡献

基础项目：[ucsandman/SideTap](https://github.com/ucsandman/SideTap)，作者 Wes Sander，MIT 许可。

本地扩展增加了以下内容：

- 使用 [jkcoxson/netmuxd](https://github.com/jkcoxson/netmuxd) 建立无线 usbmux 后端，并保留心跳。
- 将目标手机 IP 与设备身份用于网络注册。
- 针对 go-ios 1.3.2 的设备枚举限制，仅对选定设备增加兼容处理。
- 将连接入口、启动器和部分稳定性配置接入 SideTap。

本文分享的是这次实现思路与验证结果，不是原作者发布的无线功能，也不是已发布的通用安装器。

## 已确认仍有专机配置

| 位置／配置 | 当前情况 | 通用版需要什么 |
| --- | --- | --- |
| `wifi_transport.py` | 手机 UDID 和地址已经读配置；后端端口固定 | 校验配置、检测端口冲突，报错区分网络与服务 |
| `scripts/wifi_mux_compat.py` | 仍有本机 UDID 常量 | 从同一配置读取 UDID，缺失时拒绝启动，不默认控制首台手机 |
| netmuxd / 兼容层 | 本机回环端口固定；一次选择一台设备 | 每个实例独立端口与状态目录，保证隔离 |
| 环境变量与启动入口 | 本地代码中已有多处集成 | 固定上游版本，完整提供补丁或分支，不能只发两段代码 |
| 闲置刷新／自动恢复 | 本机关闭这两项 | 作为可选配置，按机型与系统测试，不强制所有人关闭 |
| 手机 IP | 由本次网络确定 | 支持手动填写／发现，验证目标身份，不能将热点网关地址写死 |

**现在复制原仓库＋示例 `.env`，不等于已安装我们的无线扩展。**这也是公开安装教程之前必须补齐的部分。

## 复现链路需要满足的条件

1. 手机已与该 Windows 主机配对，配对记录留在使用者本机。
2. 手机允许无线连接，开发者模式、WDA 签名与 UI Automation 授权有效。
3. 电脑与手机之间能访问需要的设备服务；同名 Wi‑Fi 不足以证明互通。
4. netmuxd 的心跳可工作；不能因为基本设备信息能读出，就把它关掉。
5. 对 go-ios 1.3.2 使用本次兼容层时，明确这是该版本的处理方式；升级后需重新核对，不能默认继续适用。
6. 最终从 AI 真正使用的入口完成点按和读回验收。

本次使用 netmuxd 0.4.3 Windows 发布文件；[官方发布页](https://github.com/jkcoxson/netmuxd/releases/tag/v0.4.3)。分享时让使用者自行下载对应平台文件，不分发本机配对材料。

## 模型、线缆与网络拓扑是三个不同维度

| 场景 | 当前结论 | 需要补做的验证 |
| --- | --- | --- |
| iPhone 13 自己开热点 | 完整控制已通过 | 扩大运行时间、重连与续签测试 |
| 其他 Lightning iPhone | 方案可以作为候选 | 配对、无线心跳、WDA、闲置后操作、AI 入口 |
| USB-C iPhone | 插头改变不等于控制协议已验收 | 完整安装与无线控制；17 的连线对照不算完成 |
| 有蜂窝网络的 iPad | 可研究自开热点拓扑 | 设备／系统支持、WDA 和屏幕坐标适配 |
| 仅 Wi‑Fi 的 iPad | 不能照搬“自己用蜂窝开热点” | 与电脑接第三方网络且可互通；另测 iPadOS |
| 第三台手机开热点 | 未验证 | 客户端隔离、手机地址发现、连接稳定性 |
| 家用路由器 | 未验证 | 无线配对与网络服务可达性 |
| 校园／访客网络 | 不能保证可用 | 设备隔离与网络限制 |
| Android | 这套 iOS 后端不能直接适配 | 另做 ADB／UI 自动化后端与独立权限流程 |

“可配置更多 iPhone”是合理目标；“全机型通用”需要不同设备实测，不能只依据参数改完就宣布。

## 建议的公开版结构

```text
docs/                 基础安装、无线连接、续签、故障分层
src/.../transport/    USB 与 Wi-Fi 后端，统一状态接口
scripts/              本机启动器、目标设备选择与验收
.env.wifi.example     全占位符，不含个人身份和凭据
tests/                配置、设备筛选、枚举帧、错误与重连测试
LICENSE               保留上游完整许可
THIRD_PARTY_NOTICES    依赖署名与来源
COMPATIBILITY.md      逐设备实测表，日期与版本
```

保留本机回环监听、已有的 STOP 与发送审批。连接恢复时先核对设备身份，不自动切到另一部已配对手机。系统／手机出现异常重启时应停止操作并保留诊断信息，避免重复拉起测试服务。

## 每个机型的验收表

- [ ] 初次配对、签名和触控授权完成
- [ ] 无线状态记录说明当前确实使用 Network 链路
- [ ] 无 USB 数据依赖时可读屏
- [ ] 7＋1＝8，画面读回吻合
- [ ] 闲置后＋2＝10
- [ ] 从实际 AI 工具入口＋3＝13
- [ ] 热点暂时断开时报告离线，恢复后仍选择原设备
- [ ] STOP 能阻止继续操作，发送规则未失效
- [ ] 续签后触控仍正常
- [ ] 记录机型、系统、工具版本、测试时长与失败现象

大型游戏需要额外测试，不作为基础控制验收的默认承诺。
